# blendfile: .blend spec docs, isomorphic TS reader, website

Tick `- [x]` when a milestone's proof passes, THEN `verify` its scope.

## Evidence

- VERIFIED[spec source] Blender ships no standalone spec; the normative layout is in source at commit `3fe0f2ab2a29` (main, 2026-10-17): `blenloader_core/BLO_core_blend_header.hh`, `BLO_core_bhead.hh`, `intern/blo_core_*.cc`, `makesdna/intern/dna_genfile.cc`, `makesdna/DNA_sdna_types.h`, `blenlib/intern/fileops_c.cc`.
- VERIFIED[header] 12-byte legacy `BLENDER[-_][vV]NNN`; 17-byte v1 `BLENDER17-01vNNNN`, always LE + 8-byte pointers + LargeBHead8 BC header source; Blender 5.2.2 writes `BLENDER17-01v0502` BC `input/v52.blend`.
- VERIFIED[bhead] BHead4 20 B, SmallBHead8 24 B, LargeBHead8 32 B (`code, SDNAnr, old u64, len i64, nr i64`) BC `BLO_core_bhead.hh`.
- VERIFIED[sdna] `SDNA NAME n str* pad4 TYPE n str* pad4 TLEN short*n pad4 STRC n (short type, short n, (short type, short name)*n)*`; pointer size = sizeof(ListBase)/2; SDNAnr 0 = raw bytes BC `dna_genfile.cc`, `DNA_sdna_types.h`. pad4 is relative to the DNA1 payload start, since Blender aligns in its own read buffer.
- VERIFIED[compression] gzip magic `1f 8b 08`; zstd magic `28 b5 2f fd` or skippable `184D2A5?` BC `fileops_c.cc`. Blender zstd = multi-frame + seek table: Node 24 `zlib.zstdDecompressSync` returns only frame 1 (1236 of 458736 B), `fzstd@0.1.1` decodes the full file BC scratch probe.
- VERIFIED[big endian] Blender 5.x refuses big-endian files BC `readfile.cc:1253`; the reader still decodes them per spec.
- UNKNOWN[BHead4|big-endian real files] no 32-bit or PPC Blender can run here; covered by spec-derived synthetic bytes in tests only.

## Decision

One package `blendfile` (bun, pkgroll ESM+CJS+d.ts, deps `fzstd` and `fflate` for zstd and gzip, both sync and pure JS for browser and Node). The input is `Uint8Array|ArrayBuffer`, so no fs or DOM inside the lib. Website per human request: defuss-ssg (Vite 8) + defuss JSX + defuss-shadcn; spec pages render `spec/*.md` with marked at build time, so the spec has one owner.
