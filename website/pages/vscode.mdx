<h1 class="mk-docs-content-title" id="page-title">VS Code extension</h1>
<p class="mk-docs-content-lead">Blend File Preview opens <code>.blend</code> and <code>.blend1</code> files in VS Code as a 3D view of the scene and an inspector, instead of binary text. It is built on this library and parses the file inside the editor; nothing is uploaded.</p>

<h2>Install</h2>

<p>Download the <code>.vsix</code> file above and install it from a terminal:</p>

<pre><code>code --install-extension blendfile-preview.vsix</code></pre>

<p>Or, in VS Code, open the Extensions view, choose <strong>Install from VSIX...</strong> from its <strong>Views and More Actions</strong> menu and pick the file. Cursor, VSCodium and other VS Code based editors install it the same way. To build it yourself, run <code>make vscode-package</code> in the <a href="https://github.com/Mansi1/blendfile">repository</a>.</p>

<p>Once installed, the preview is the default editor for <code>{"*.blend"}</code> and <code>{"*.blend1"}</code> files. To pick it explicitly, right-click a file in the Explorer and choose <strong>Open Blend File Preview</strong>.</p>

<h2>3D view</h2>

<ul>
  <li><strong>The scene as Blender's viewport shows it:</strong> meshes with their materials, lights, cameras and empties, placed with the world matrices Blender computes (parents, every rotation mode, delta transforms). Objects hidden in the viewport start hidden.</li>
  <li><strong>Four shading modes:</strong> Wireframe, Solid (studio light and viewport display colors), Material (Principled BSDF base color, metallic, roughness and emission with image textures) and Rendered (the scene's own lights, shadows and world color).</li>
  <li><strong>Navigation like Blender:</strong> drag to orbit, Shift-drag to pan, wheel to zoom; 1, 3 and 7 for front, right and top views, 0 for the scene camera, Home to frame everything.</li>
  <li><strong>Outliner and status line:</strong> show, hide and select objects; the status line counts vertices, faces and triangles and names objects with modifiers.</li>
</ul>

<p>Image textures show in Material and Rendered modes when an Image Texture node feeds the Principled BSDF's Base Color, Metallic, Roughness, or Normal through a Normal Map node. Packed images come from the file itself; external images are read next to the <code>.blend</code> file, also from its <code>textures</code> folder when the saved path belongs to another machine. PNG, JPEG, WebP, BMP, GIF and OpenEXR are supported and scaled to at most 2048 pixels.</p>

<p>The file stores meshes before modifiers, so subdivision, mirror and other modifiers are not applied. Curves, text and volumes only get geometry when Blender evaluates them and are listed as not drawn. Node setups beyond an image feeding the Principled BSDF (Mix, Color Ramp, procedural textures) are not rendered.</p>

<h2>Inspector</h2>

<figure class="screenshot">
  <img src="/assets/vscode-inspector.png" alt="The Inspector tab: the saved thumbnail of a cube, the scene with its frame range, and the datablocks grouped by type." width="1280" height="720" loading="lazy" />
  <figcaption>The Inspector tab with the saved thumbnail and the datablocks.</figcaption>
</figure>

<ul>
  <li><strong>Thumbnail and scenes:</strong> the preview image Blender saved and each scene's frame range.</li>
  <li><strong>Datablocks:</strong> objects, meshes, materials, scenes and the rest, grouped by type, with a filter.</li>
  <li><strong>Struct browser:</strong> every member of a datablock as the file's own SDNA describes it. Click a pointer to follow it; <strong>Copy as JSON</strong> copies the open struct. The <a href="/inspector.html">inspector on this site</a> is this same preview, running in the browser.</li>
</ul>

<p>It reads files from Blender 2.5 to 5.x, plain, gzip or zstd compressed, and reloads when Blender saves the file again.</p>

<h2>Privacy</h2>

<p>The extension has no network access and sends no telemetry. The file is parsed inside the preview. The only other files it reads are images (by file extension) that a material names, and only to show them in the preview.</p>
